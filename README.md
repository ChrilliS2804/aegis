# Aegis

> AI Portfolio Operating System

## Vision
Aegis is an AI-native platform for long-term investors. It combines live financial data via the Fiscal.ai MCP server with a modular investment engine to provide transparent portfolio analysis and investment decision support.

## Core Principles
- Long-term investing
- Explainable AI
- MCP-native integrations
- Clean Architecture
- Test-driven development
- Cloud-native

## Project Status
🚧 Sprint 0 – Foundation

The initial focus is establishing the repository structure, architecture, specifications and engineering standards before implementing business logic.
