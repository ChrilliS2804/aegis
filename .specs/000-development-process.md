# SPEC-000 — Development Process

Status: READY

## Purpose
Defines the engineering workflow for Aegis.

## Lifecycle
Idea -> Specification -> ADR -> Issue -> Implementation -> Pull Request -> Review -> Merge

## Roles
- Product Owner: Vision and priorities
- CTO: Architecture and reviews
- Kiro: Implementation and tests

## Rules
- No implementation without specification.
- No direct commits to main.
- Use feature branches and pull requests.
